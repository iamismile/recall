# Recall Keyboard Shortcuts (sample eval document)

Recall is designed to be used without leaving the keyboard. The web interface binds several global shortcuts so power users can search, upload, and navigate results quickly.

Cmd or Ctrl plus K focuses the search bar from anywhere in the app. Pressing the combination blurs whatever element currently has focus and moves the caret into the query input, so you can start typing a question immediately regardless of where you were scrolling.

Cmd or Ctrl plus U opens the file picker to upload a document. This triggers the same hidden file input that the upload card uses, letting you add a new file without clicking the dashed upload area. After you choose a file the indexing flow runs exactly as if you had used the mouse.

Arrow keys move the focus between the cited source chunks. When an answer contains citation markers such as [1] or [2], you can press the up and down arrows to step through the corresponding source cards; the focused card is highlighted and scrolled into view. This makes it easy to verify a claim against its source without reaching for the mouse.

Additional shortcuts include Escape to clear the current query and Return to submit it. On the document manager, Tab cycles through the delete buttons so you can remove several files in a row. These bindings are intentionally minimal and do not conflict with the browser's own shortcuts.

If you are on a platform without a Cmd key, Control behaves identically. The shortcuts are documented in the help panel and can be disabled in settings for users who find them intrusive.
