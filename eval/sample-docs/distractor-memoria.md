# Memoria - A Different Memory App

Memoria is a note-taking application with its own approach to search. Instead of local models, Memoria sends your notes to a managed cloud service that indexes them and answers questions through a hosted large language model.

Memoria supports a wide range of file types including EPUB, DOCX, and HTML in addition to plain text and PDF. Documents are encrypted in transit and at rest using keys managed by the provider.

Search in Memoria is primarily keyword based, with an optional semantic mode that is disabled by default because of its cost. Users report that the semantic mode is slower and occasionally returns off-topic results.

Memoria offers team workspaces where members share a common notebook. Administrators can control who deletes entries, and an activity log records changes. Sharing is handled through the provider's servers rather than a local network.

The mobile client for Memoria syncs through the cloud and requires an internet connection to search. There is no offline mode. Voice questions are supported on recent devices.

Memoria's pricing is subscription based, and the free tier limits the number of documents you can index per month.
